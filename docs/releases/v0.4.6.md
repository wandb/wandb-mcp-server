## Summary

Interactive W&B line plots render inline in MCP Apps hosts, with useful text
summaries in other clients. No deployment channel is available yet.

## Changes

- **Inline line plots:** `render_wandb_line_plot_tool` reads up to 10 runs and
  5 metrics with bounded history reads. Charts include run legends, hover
  values, drag zoom, double-click reset, host themes and an Open in W&B link.
- Inputs now accept native camelCase W&B line-plot `config` (including report
  panel configs); output schema `wandb.graph/v1` mirrors Graph series, styles,
  metadata and axes. Supports server-side smoothing, sampled exact-match
  config/run-group aggregation, uncertainty bands, log scales and overrides.
  Unsupported data-changing config returns explicit `unsupported_config`;
  ignored native cosmetics are recorded in coverage. Timestamps are milliseconds.
- Step-axis zoom can requery windows within the deployment's history range cap.
  Other zooms are local. Per-run failures preserve successful curves; sampling
  and truncation remain explicit. The tool is read-only in the `models` group.
- The offline HTML resource embeds uPlot under its MIT license. No external
  scripts, styles or data connections are required. Optional
  `WANDB_MCP_APP_DOMAIN` configures host-specific sandbox origins.

## Compatibility

Python and SDK dependency ranges are unchanged. Clients without MCP Apps see
per-run metric statistics and W&B links rather than an interactive chart.
App rendering, links and zoom requery depend on host support and permissions.

## Breaking changes and migration

No existing tool is removed. Refresh tool discovery to see the additional
read-only tool. Profile tool counts increase by one. Claude operators should
configure the optional app domain following the README's host instructions.
