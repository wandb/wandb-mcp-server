## Summary

This candidate targets bounded secret resolution, explicit secret versions and
recovery from session initialization failures. Component changes and their
validation are tracked in the release PR; no channel is available yet.

## Compatibility

Python 3.11 and 3.12 and the MCP/W&B SDK ranges remain unchanged from v0.4.4.
Tool schemas and profile selections remain unchanged.

## Breaking changes and migration

Pending component qualification. Existing secret configuration defaults are
preserved. Rotating the session signing key requires clients to reconnect.

## Validation

Pending complete candidate, isolated-wheel, compatibility and security gates.

## Immutable artifacts

Signed tag, source/tree identity, checksums, attestations and image digests are
pending. No artifact or qualification evidence is inherited from v0.4.4.

## Rollback

Public source fixes forward. Hosted rollback must restore the previous image
and compatible configuration while retaining an approved, usable signing key.
A revoked key must not be restored to make old sessions work.
