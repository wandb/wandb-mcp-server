## Summary

This candidate adds three offline, stateless-compatible MCP Apps for CoreWeave
Agent Lens, Weave Agents, and ARIA—an interactive Agent Lens Insights Explorer
(`ui://wandb/agent-lens-insights.html`) wired to a 1-call
`render_agent_lens_insights_tool` overview entrypoint, an interactive
Conversation & Span Trajectory Inspector (`ui://wandb/agent-conversation.html`)
attached in-place to `get_weave_agent_conversation_tool` and
`get_weave_agent_trace_tool`, and an interactive ARIA Studio & Parallel
Sub-Agents Monitor (`ui://wandb/aria-agent.html`) attached in-place to
`aria_send_message`, `aria_get_turn`, `aria_list_threads`, and
`aria_get_thread`—while enforcing client-side `https://` URL guards across all
four shipped MCP Apps. No deployment channel is available yet.

## Changes

- **Interactive Agent Lens Insights Explorer MCP App (`agent-lens` extension):**
  - Adds `render_agent_lens_insights_tool` and self-contained offline `ui://wandb/agent-lens-insights.html` (`@modelcontextprotocol/ext-apps` + `zod`, MIT-licensed) gathering coverage weeks, clustering status, failure and intent category/cluster breakdowns with impact metrics (`no_failure` filtered out, `failingTurnCount` computed cleanly), and optional failure attributions in a single parallel call.
  - Matches the Agent Lens product layout with two tabs (`Agent failures`, `User intents`), `24h` / `7d` / `30d` window buttons (`window_days=14` preserved for API callers), `% of turns` category and nested cluster bars, impact rows, example-turn drilldown, embedded multi-turn conversation preview, `https://`-validated Forge deep links (`https://forge.coreweave.com/agent-lens/<entity>/<project>/...`), and `failureClusterToMarkdown` coding-agent brief synchronization via `ui/update-model-context`.
- **Interactive Conversation & Span Trajectory Inspector MCP App (`agents` group):**
  - Attaches self-contained offline `ui://wandb/agent-conversation.html` in-place to `get_weave_agent_conversation_tool` and `get_weave_agent_trace_tool` (with optional `selected_failure` pinning), preserving the exact existing JSON string in `content[0].text` for text-only MCP callers while emitting structured `wandb.agent_conversation/v1` payloads for UI-capable hosts.
  - Provides `Thread` and `Spans` views, an `Agent failures` list (`get_agent_lens_failure_attributions_tool`) with clickable inline span citations and evidence-span highlighting in the waterfall, `read-write`-gated human reactions/notes and Agent Lens tag assignment, and click-to-debug `ui/update-model-context` synchronization with failure reasons.
- **Interactive ARIA Studio & Parallel Sub-Agents MCP App (`aria` extension):**
  - Attaches self-contained offline `ui://wandb/aria-agent.html` in-place to `aria_send_message`, `aria_get_turn` (with optional concurrent `parallel_turn_ids` batch polling up to 15 additional sub-agent turns), `aria_list_threads`, and `aria_get_thread` without increasing tool counts.
  - Adapts automatically between a focused 1-to-1 IDE-to-ARIA conversation studio (live elapsed clock, sandbox/API tool step chips, inline `network_access` permission grants and `agent_questions` replies, Markdown/table rendering, and thread continuations) and a `Fleet grid` / `Split focus` monitor for 2..N parallel asynchronous ARIA sub-agents with `ui/update-model-context` synchronization.
- **Shared offline MCP App bundler & URL scheme hardening:**
  - Factors shared `PostMessageTransport`, theme/font synchronization, `^https://` client-side link validation across `line-plot.html`, `agent-conversation.html`, `agent-lens-insights.html`, and `aria-agent.html`, SHA-256 bundle integrity checks, and unified `THIRD_PARTY_NOTICES.txt` generation.

This release retains the orthogonal selector architecture from
[v0.4.6](v0.4.6.md) while expanding `agent-lens` (13 read, 2 write) and
keeping `models-only` and `models-weave` unchanged within the 128 KiB
`tools/list` budget.

## Compatibility

Python 3.11 and 3.12 and the MCP/W&B SDK ranges remain compatible with v0.4.6.
Existing tool names and `content[0].text` JSON payloads in `models`, `weave`,
`agents`, `agent-lens`, and `aria` are preserved; write actions remain hidden
and rejected when `WANDB_MCP_ACCESS_MODE=read-only`.

## Breaking changes and migration

None. `get_weave_agent_conversation_tool` and `get_weave_agent_trace_tool`
preserve their exact text output while adding `structuredContent` and UI
resource metadata for MCP Apps hosts.
