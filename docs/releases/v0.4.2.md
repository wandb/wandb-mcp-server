## Summary

This release adds an opt-in, read-only Agent Lens surface for W&B-hosted MCP
without changing the default local or Dedicated tool sets. It also includes the
public 0.4.1 compatibility and telemetry repairs; the hosted image preserves
the separately versioned 0.4.1.1 customer-image compatibility wrapper and Azure
health-probe behavior.

## Highlights

- Nine read-only tools expose Agent Lens Insights and conversation-tag data.
- W&B-hosted deployments explicitly select the combined Models, Weave, Agents,
  and Agent Lens profile.
- Default, Dedicated, and customer profiles do not register Agent Lens tools.

## Breaking changes and migration

None for existing local, Dedicated, or customer deployments. Agent Lens is not
enabled by an image upgrade alone.

## Compatibility

- Python 3.11 and 3.12.
- MCP SDK 1.28.1 or newer and lower than 2.0.
- The existing 0.4.1 tool profiles and legacy customer-image bridge remain
  available unchanged.

## Operator changes

The Agent Lens profile requires an explicit validated HTTPS origin. W&B-hosted
deployment policy supplies that origin and selects the shared-only profile;
Dedicated workloads reject that profile.

## Security and privacy

Agent Lens requests forward the current caller's W&B bearer credential only to
the operator-reviewed HTTPS origin. Redirects are rejected. The tools are
read-only, retain caller-scoped authorization, and do not add credentials,
arguments, project identifiers, or response bodies to telemetry or release
evidence.

## Known limitations

- Agent Lens remains unavailable to Dedicated managed workloads in v0.4.2.
- Public source, hosted deployment, and customer publication remain separate
  release channels.
